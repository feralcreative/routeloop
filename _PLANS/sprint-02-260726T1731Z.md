# Sprint 2: User profiles

## feat/user signup, profiles, account managment

1. Profile setup
   - allow users to create and edit a personal profile
     a. On the splash, isntead of "Continue with Google" have a sign in button and below it a link to "Not a member yet? Sign up."
     b. Profile should be first name, last name, user/display name, address, city, state, zip - give checkboxes/options to share last name, and add home address to all rides by default.
     c. Profiles should have optional fields for payment like Cash App, Venmo, Paypal, Zelle, etc. (for before-charges like hotel reservations, and during charges like shared gas, meals, etc. split along the trip)
     c. Users should be able to add people to their rider list by username, email, phone. Because this is an alpha, restrict that feature until/unless I give them permission.
     d. Profiles is also the place where people should edit/add their own custom places.

In our next sprint, we will add an admin panel that allows me to manage these users. Don't worry about it in this sprint.
