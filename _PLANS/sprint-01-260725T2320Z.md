# Changes to Routeloop.app

1. There's no easy/obvious way to get home from the map/builder page. Put a hamburger menu at the top right or something. Users should easily get to anywhere from anywhere.

2. Users should have a way to add permanent markers to the map in various categories and be able to turn them on and off as layers on the map. Users should be able to add them to their saved Places from the map, and/or go to /places and edit/sort/move categories, etc.

3. Re: icons for custom places, users should be able to set the default icons for those stops (e.g. home is always home, chevron is always gas) but be able to change them when added to a given route.
